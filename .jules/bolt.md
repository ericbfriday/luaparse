## 2024-06-18 - Scope Tracking Performance Optimization
**Learning:** `luaparse` tracks identifier scope by storing identifier strings in an array and using `indexOf` to check for existence. When nested scopes are created, `Array.prototype.slice()` is used to copy the parent scope's identifiers. While `slice` is fast, `indexOf` has O(n) lookup time. Using an `Object.create(null)` dictionary makes lookups O(1). However, memory explicitly warns: "When optimizing nested block scopes, while dictionary-based lookups (`Object.create(null)`) are faster than array `indexOf` for tracking identifiers, copying these dictionaries using `Object.assign` is significantly slower than array `.slice()`. To maintain performance when entering new block scopes with dictionaries, use prototypical inheritance (`Object.create(parentScope)`) rather than shallow copying." Using prototypical inheritance for scope tracking yielded a dramatic 15x speedup in isolated scope tests.
**Action:** Use prototypical inheritance (`Object.create(parentScope)`) for nested scope dictionaries instead of `Object.assign`. Use `Object.prototype.hasOwnProperty.call(scope, name)` to check for current scope declaration to avoid shadowing issues.
