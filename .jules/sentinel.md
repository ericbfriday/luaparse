## 2024-05-25 - [High] Prototype Pollution via Lua Labels
**Vulnerability:** The Lua parser (luaparse.js) used regular JavaScript object literals (`{}`) to store user-defined label names in its scope tracking dictionary (`scope.labels`). This allowed an attacker providing crafted Lua code containing `::__proto__::` to manipulate the `Object.prototype` (Prototype Pollution).
**Learning:** Using `{}` as a dictionary for storing user-controlled string keys is unsafe because special keys like `__proto__`, `constructor`, or `hasOwnProperty` can override inherited properties and potentially lead to prototype pollution and unexpected behaviors.
**Prevention:** When storing user-supplied strings as keys in a dictionary, always initialize the dictionary with a null prototype using `Object.create(null)` instead of `{}`. For compatibility with older environments without `Object.create`, use a safe fallback like `Object.create ? Object.create(null) : {}` combined with `hasOwnProperty` checks before property access.
