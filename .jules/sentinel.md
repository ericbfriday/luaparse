## 2024-05-20 - [Prevent Prototype Pollution in Dictionary Objects]
**Vulnerability:** Prototype pollution vulnerability in `luaparse.js` where user-supplied string keys are used directly to index an object created with `{}` (e.g., `labels: {}`). Even with `hasOwnProperty` checks before reading, writing to a key like `__proto__` can pollute `Object.prototype`.
**Learning:** `Object.prototype.hasOwnProperty` only protects against *reading* from the prototype chain, not *writing* to `__proto__`. If a user controls the key being written (like a Lua label name), they can overwrite properties on `Object.prototype`. The `__proto__` property is treated specially by the JavaScript engine when using assignment to an object literal.
**Prevention:** Always initialize dictionary objects intended to store user-supplied string keys with `Object.create(null)` instead of object literals `{}`. This creates an object with a `null` prototype, making it immune to `__proto__` pollution via assignment.
